# FASTECH SYSTEM

Sistema de Inventario desarrollado con React, Node.js y MariaDB.

---

## Descripción

FASTECH SYSTEM es una aplicación web para la gestión de inventario empresarial.

El sistema permite:

- Inicio de sesión
- Gestión de productos
- Registro de compras
- Registro de clientes
- Dashboard administrativo
- Reportes
- Configuración del sistema

---

## Tecnologías Utilizadas

### Frontend
- React
- JavaScript
- CSS

### Backend
- Node.js
- Express

### Base de Datos
- MariaDB / MySQL

### Control de Versiones
- Git
- GitHub

## Funcionalidades

### Login

### Inventario

- Registro de clientes

### Dashboard
- Estadísticas generales del sistema

## Instalación

### Clonar repositorio

```bash
git clone https://github.com/TU-USUARIO/inventario-react.git
```

### Entrar al proyecto

```bash
cd inventario-react
```

### Instalar dependencias

```bash
npm install
```

### Ejecutar proyecto

```bash
npm start
```
